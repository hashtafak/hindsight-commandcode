# hindsight-coding-agents — Command Code distribution

> **Command Code distribution (unofficial).** A standalone distribution of
> `@vectorize-io/hindsight-coding-agents` carrying the **`commandcode`** harness — native
> SessionStart/Stop hooks for [Command Code](https://commandcode.ai) — ahead of any upstream
> release. The npm package name is deliberately left as upstream so installs keep the exact
> directory layout and entry-identification paths the installer and tests rely on. Upstream base:
> `vectorize-io/hindsight` @ `5a672f0cd` + `feat/commandcode-harness`.
